# Calabaza Roulette

Ruleta de Halloween para 2 jugadores online (Node.js + WebSockets).

## Ejecutar en local
    npm install
    npm start
Abre http://localhost:3000 en dos pestañas (o dos dispositivos en la misma red), crea una sala en una y únete con el código en la otra.

## Subir online
Funciona en cualquier host con Node (Render, Railway, Fly.io, un VPS). Comando de inicio: `npm start`. El puerto se toma de la variable `PORT`.
